# Database utility scripts

Ручные служебные скрипты для локальной разработки и обслуживания БД.
Они не запускаются приложением автоматически.

- `check_db.py` — выводит краткую сводку содержимого БД.
- `init_admin.py` — устаревший ручной вариант создания администратора; production использует `core/init_db.py`.
- `seed_matrix.py` — импортирует Android- и Flutter-матрицы из `data/competency_matrices/`.
- `seed_programs_and_tasks.py` — создаёт демонстрационные программы, материалы и задания.
- `seed_demo_data.py` — полностью пересоздаёт таблицы и предназначен только для одноразовой локальной демонстрационной БД.

Перед запуском seed-скриптов обязательно проверьте `DATABASE_URL`. Никогда не запускайте `seed_demo_data.py` для БД с нужными данными.
