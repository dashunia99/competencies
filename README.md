# Компетенции

Backend-сервис для управления компетенциями и обучением сотрудников. API реализован на FastAPI, работа с данными — через SQLAlchemy, основное хранилище — PostgreSQL.

## Структура проекта

| Путь | Содержание |
|---|---|
| `api/` | Обработчики API: аутентификация, пользователи, обучение и программы обучения. |
| `app/models/` | SQLAlchemy-модели пользователей, ролей, стеков, компетенций, программ, заданий и прогресса. |
| `app/schemas/` | Схемы пользователей, используемые в приложении. |
| `app/services/` | Сервисный слой для операций с пользователями. |
| `app/core/` | Настройки интеграции с S3/MinIO и клиент для загрузки файлов и генерации временных ссылок. |
| `core/` | Подключение к базе данных и функции безопасности, включая работу с паролями, токенами и ролями. |
| `schemas/` | Pydantic-схемы запросов и ответов для аутентификации, пользователей, обучения и программ. |
| `migrations/` | Конфигурация Alembic и история изменений схемы базы данных в `versions/`. |
| `bd/` | SQL-файлы со схемой базы данных и тестовыми данными. |

## Файлы в корне

- `main.py` — создаёт FastAPI-приложение, подключает API-маршруты и служебную проверку состояния.
- `alembic.ini` — настройки Alembic.
- `check_db.py` — выводит сводку о данных в базе.
- `seed_demo_data.py` — пересоздаёт схему `public` в базе и заполняет её демонстрационными данными.
- `seed_matrix.py` — загружает матрицы компетенций из Excel-файлов; перед импортом очищает компетенции соответствующего стека.
- `Android матрица компетенций.xlsx`, `Flutter матрица компетенций.xlsx` — исходные матрицы компетенций.
- `requirements.txt` — список Python-зависимостей проекта.

## Основные возможности API

Маршруты объединены под префиксом `/api/v1`. Они охватывают вход и профиль пользователя, управление пользователями, программы обучения, материалы, задания и учебный прогресс. Точный перечень маршрутов и их параметры определены в модулях `api/`.
