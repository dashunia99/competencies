# competencies
# Система управления компетенциями (Backend)

Это бэкенд часть проекта, написанная на FastAPI + PostgreSQL.

## 🚀 Статус готовности API (Эндпоинтов)

Здесь мы отмечаем, какие ручки уже реализованы и готовы к использованию фронтендом.

### 1. Авторизация и Управление пользователями
- [ ] `POST /api/v1/auth/login` — Вход и получение токена
- [ ] `POST /api/v1/users/` — Создание пользователя (Админ)
- [ ] `POST /api/v1/users/{user_id}/block` — Блокировка пользователя

### 2. Личный кабинет (Сотрудник)
- [ ] `GET /api/v1/users/me` — Получение профиля (имя, стек, грейд)
- [ ] `GET /api/v1/users/me/matrix` — Матрица компетенций
- [ ] `GET /api/v1/users/me/history` — История оценок

### 3. Инфраструктура
- [x] Базовые настройки (FastAPI, SQLAlchemy, Pydantic)
- [x] Подключение к PostgreSQL
- [x] Создание моделей БД (`models/`)
- [x] Создание базовых схем (`schemas/`)
